# Cours d’algèbre — M1

Ce dépôt contient les documents destinés aux étudiants pour le cours d’algèbre 1 de M1 PMG.

## Polycopié

Le polycopié du cours sera mis à jour régulièrement au fil du semestre. La version publiée ici est la **version étudiante** : elle ne contient pas les annotations internes utilisées pour la préparation du cours.

Pour chaque séance, le polycopié indiquera les sections à lire ou à revoir ainsi que les principaux objectifs de travail.

## Organisation du dépôt

Le dépôt contiendra notamment :

- le polycopié du cours au format PDF ;
- les indications de lecture et de travail associées aux différentes séances ;
- le cas échéant, d’autres documents distribués pendant le cours ou les TD.

## Utilisation

Le lien vers ce dépôt est également disponible sur **PLUBEL**. Les annonces et informations pratiques relatives au cours restent publiées sur PLUBEL ; ce dépôt sert principalement à mettre à disposition les documents de cours dans leur version la plus récente.

Il est conseillé de consulter cette page régulièrement afin de disposer de la dernière version du polycopié.
